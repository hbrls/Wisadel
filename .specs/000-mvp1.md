Rime 整段润色输入插件（MVP）技术规格书

## 1. 目标（Goals）

本系统旨在基于 **Windows Rime（小狼毫）+ Lua**，实现一种"输入法态的长文本润色工具"，核心目标是：

* 基于 Windows 标准版 Rime（小狼毫）**插件化扩展**，无源码修改
* 实现**整段文本暂存 → 整段润色 → 一次性上屏**的完整管道
* 复用 Rime 原生拼音转汉字能力
* 支持**长文本**（≥140 字符，包含换行）
* 为独立悬浮 GUI 提供标准数据/指令交互能力
* 用户可**独立安装/卸载**

### 1.1 非目标（Non-Goals）

* 不实现拼音 → 汉字、五笔 → 汉字等输入法转换逻辑（复用原生）
* 不优化语言模型、词频或联想
* 不引入外部 GUI 或系统级能力
* 不支持多候选、多轮润色
* 不修改 Rime 源码
## 2. 整体架构（插件式，解耦无依赖）

```
┌─────────────────────────────────────────────────────────────┐
│                    标准版 Rime（小狼毫）                       │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 原生核心：拼音转码、候选生成、TSF 上屏、Context 上下文管理   │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 插件层（本扩展）                                         │  │
│  │  • Lua 脚本（核心逻辑）                                   │  │
│  │  • Schema 配置（加载/快捷键）                             │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
┌─────────────────────────┐     ┌─────────────────────────┐
│    独立悬浮 GUI           │     │   共享内存              │
│   （外部项目）             │     │  Rime-Weasel-Context   │
│                         │     │                         │
│  • 数据读取               │◄────│  • para_mode (bool)    │
│  • 指令触发               │     │  • para_buffer (str)   │
└─────────────────────────┘     └─────────────────────────┘
```

### 核心原则

* **Rime 扩展为唯一状态源**：负责所有业务逻辑
* **GUI 仅做「数据读取 + 指令触发」**：无状态存储/修改
* **交互方式**：共享内存读取 + 系统快捷键模拟

### 架构定位

> **不是实现一种输入法，而是利用 Rime 的输入拦截、候选展示与上屏机制，实现"汉字 → 汉字"的润色确认管道。**
## 3. 核心技术点（Rime 扩展侧）

### 3.1 载体与加载

| 项目 | 说明 |
|------|------|
| **核心实现** | Lua 5.1 脚本（Rime 原生内置）+ 自定义 Schema 配置文件 |
| **加载方式** | 文件放入 Rime 用户目录（`%AppData%\Rime`），执行「重新部署」即可加载 |
| **分发形式** | 纯文本文件，用户直接复制即可，卸载仅删除文件 + 重新部署 |
| **环境依赖** | 无额外环境，Lua 由 Rime 原生内置 |

### 3.2 全局上下文变量（核心数据载体）

在 Rime 全局 Context 中定义 2 个自定义变量，为 GUI 提供唯一数据读取源，**仅在 Lua 脚本内修改**：

| 变量名 | 类型 | 初始值 | 核心作用 |
|--------|------|--------|----------|
| `para_mode` | bool | `false` | 整段模式标记：`true`=开启/暂存，`false`=关闭/原生模式 |
| `para_buffer` | string | `""` | 整段文本暂存区，UTF-8 编码，追加原生选字结果，支持无上限长文本 |

### 3.3 核心钩子实现（基于 Rime 原生 Lua 钩子）

所有钩子仅实现正向流程，屏蔽原生冲突逻辑，核心为**拦截 → 暂存 → 润色 → 提交**闭环：

| 钩子 | 触发时机 | 核心职责 |
|------|----------|----------|
| `init` | Rime 引擎启动时 | 初始化 `para_mode` 和 `para_buffer`，避免 GUI 读取空值 |
| `processor_key_event` | 全局按键事件 | 识别自定义快捷键，实现整段模式开关 + 提交触发；整段模式开启时屏蔽 Rime 原生候选确认上屏逻辑（返回 `true` 拦截） |
| `context_update` | Rime 上下文变化（选字/删改） | 将原生选字文本实时追加至 `para_buffer`，同步处理原生删改操作，保证暂存区与用户输入一致 |
| `composer_commit` | 上屏前最后拦截点 | 读取 `para_buffer` 整段文本执行润色，将润色后文本赋值给 Rime 原生提交字段，触发一次性 TSF 上屏；上屏后重置 `para_mode=false` + 清空 `para_buffer` |

### 3.4 快捷键定义（可配置，无原生冲突）

在 Schema 中声明以下核心快捷键，支持用户自定义修改，为 GUI 提供统一指令触发入口：

| 功能 | 推荐快捷键 | 触发逻辑 |
|------|------------|----------|
| 开启整段模式 | `Ctrl+Shift+P` | `para_mode=true`，进入暂存状态 |
| 关闭整段模式 | `Ctrl+Shift+X` | `para_mode=false` + 清空 `para_buffer`，恢复原生模式 |
| 整段润色上屏 | `Ctrl+Enter` | 触发 `composer_commit`，润色后一次性上屏，完成后重置状态 |
| 清空暂存区 | `Ctrl+Backspace` | 仅清空 `para_buffer`，保留整段模式 |

### 3.5 核心能力要求

| 能力 | 要求 |
|------|------|
| **原生能力复用** | 全程不修改 Rime 转码/候选/词库逻辑，保留拼音输入、联想、简繁转换、原生删改能力 |
| **润色能力** | 基础文本优化（标点规范化、空格清理、无语义修改），润色处理 ≤100ms/200字 |
| **数据暴露** | Context 变量实时同步至 Rime 原生共享内存（Rime-Weasel-Context），供 GUI 读取，编码为 UTF-16 LE，格式为标准 JSON |
| **上屏能力** | 润色后文本通过 Rime 原生 TSF 框架提交，兼容所有 Windows 标准输入框，实现一次性整段上屏，无分段 |

### 3.6 与外部 GUI 的交互规范

| 交互方向 | 规范 |
|----------|------|
| **GUI 读 Rime** | GUI 通过 Rime 原生共享内存读取 `para_mode` 和 `para_buffer`，Rime 扩展仅负责数据写入，不做反向通信 |
| **GUI 控 Rime** | GUI 通过模拟系统快捷键触发 Rime 扩展逻辑，Rime 扩展仅负责快捷键拦截，不依赖 GUI 任何指令格式 |
| **状态唯一性** | 所有 `para_mode`/`para_buffer` 的修改仅在 Lua 脚本内执行，GUI 无任何修改权限 |

## 4. 核心概念定义

### 4.1 原始输入文本（Raw Input Text）

* 指用户在润色输入模式下输入的完整文本
* 支持任意字符与换行符
* 仅存在于输入法内部状态中（`para_buffer`）
* **在任何情况下都不会直接上屏**

### 4.2 润色结果文本（Polished Text）

* 由原始输入文本经润色逻辑生成
* 在候选阶段/提交时作为最终内容展示
* 在 Accept 后作为最终上屏内容

### 4.3 整段模式（Para Mode）

* `para_mode=true` 时进入的特殊状态
* 用户输入的汉字文本被暂存至 `para_buffer`，而非直接上屏
* 通过快捷键触发润色和一次性上屏

## 5. 数据模型

### 5.1 输入

| 属性 | 说明 |
|------|------|
| **类型** | 字符串 |
| **内容** | 已存在的汉字文本（经 Rime 原生拼音转汉字） |
| **特性** | 可包含换行，长度不设严格上限（以 Rime 实际能力为准） |

### 5.2 输出

| 属性 | 说明 |
|------|------|
| **类型** | 字符串 |
| **内容** | 润色后的完整汉字文本 |
| **数量** | 1 个（MVP） |
## 6. 润色逻辑（MVP 约束）

* **实现方式**：Lua 脚本
* **规则来源**：
  * 正则表达式
  * 字符串替换
  * 简单启发式规则
* **约束**：
  * 不接入云端
  * 不做多版本输出
  * 基础文本优化（标点规范化、空格清理、无语义修改）

## 7. 取消与异常处理（MVP 最小定义）

### 7.1 用户取消

* 在整段模式下，用户可通过以下方式取消：
  * 按下关闭整段模式快捷键（`Ctrl+Shift+X`）
* 取消后：
  * 不上屏任何文本
  * 清空 `para_buffer`
  * `para_mode` 置为 `false`

### 7.2 润色失败

* 若润色逻辑执行失败：
  * 不生成提交内容
  * 不上屏任何文本
  * 系统回到初始状态
  * 用户可继续输入或清空

## 8. 输入内容生命周期

| 阶段 | 原始输入文本 | 润色结果文本 |
|------|-------------|-------------|
| 输入阶段 | 存在于 `para_buffer` | - |
| 润色阶段 | 存在于 `para_buffer` | 生成中 |
| 候选/提交阶段 | 被销毁 | 存在于提交字段 |
| Accept 后 | - | 写入目标输入框 |

## 9. 文件组成（Rime 用户目录部署）

| 文件名 | 类型 | 核心作用 |
|--------|------|----------|
| `rime_para_editor.lua` | Lua 脚本 | 实现初始化、钩子、暂存、润色、状态管理等所有核心逻辑 |
| `rime_para_editor.schema.yaml` | Schema 配置 | 加载 Lua 脚本、声明快捷键、关联拼音输入法（如朙月拼音） |

## 10. 验收标准（可量化）

### 10.1 功能验收

| 验收项 | 验收标准 |
|--------|----------|
| **插件加载** | 文件放入 Rime 用户目录，执行「重新部署」，无报错，Rime 正常启动 |
| **模式开关** | 按下开启/关闭快捷键，`para_mode` 实时切换为 `true`/`false`，共享内存中数据同步更新 |
| **整段暂存** | 开启整段模式后，原生拼音选字，文本实时追加至 `para_buffer`，原生删改操作同步更新暂存区，无丢失/乱码，支持 ≥500 字长文本 |
| **原生能力保留** | 整段模式下，Rime 拼音输入、候选选择、联想、简繁转换、原生删改功能均正常可用 |
| **整段润色** | 触发润色上屏快捷键，`para_buffer` 文本完成基础润色（标点/空格优化），无语义错误 |
| **一次性上屏** | 润色后文本通过 Rime 原生 TSF 框架一次性上屏至 Windows 标准输入框，无分段、无丢失、无乱码 |
| **状态重置** | 上屏完成后，`para_mode` 自动置为 `false`，`para_buffer` 自动清空，共享内存数据同步更新，恢复 Rime 原生即时上屏模式 |
| **快捷键自定义** | 修改 Schema 配置中的快捷键，Rime 扩展可正常识别并触发对应功能 |
| **独立部署** | 插件可单独安装/卸载，不影响 Rime 原生功能，卸载后无任何残留 |

### 10.2 性能验收

| 验收项 | 验收标准 |
|--------|----------|
| **响应速度** | 快捷键触发 → 状态切换 ≤100ms，选字 → 暂存区更新 ≤50ms |
| **润色速度** | 200 字以内文本润色处理 ≤100ms，500 字长文本润色 + 上屏 ≤200ms |
| **资源占用** | 插件运行时无额外 CPU/内存占用，复用 Rime 引擎资源，Rime 整体运行无卡顿 |
| **数据同步** | Context 变量与 Rime 共享内存数据同步无延迟，GUI 可实时读取到最新状态/文本 |

### 10.3 兼容性验收

| 验收项 | 验收标准 |
|--------|----------|
| **Rime 版本** | 兼容 Windows 小狼毫 ≥0.14.3 官方标准版 |
| **系统版本** | 兼容 Windows 10/11 64 位主流版本 |
| **应用兼容** | 润色后文本可正常上屏至微信/QQ/Office/浏览器/记事本等 Windows 标准输入框 |
| **插件兼容** | 与 Rime 生态内其他 Lua 插件（如繁简转换、词库扩展）可同时加载，无功能冲突 |
